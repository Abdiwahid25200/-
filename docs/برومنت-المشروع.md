# 🚨 أهم تحذير: الكود مكرّر بين الملفين

ملف `admin.html` **يحتوي نسخة كاملة من كود موقع الزبون** (نفس الصفحات والدوال والترجمات)، لكنه **يخفيها** عبر `body.admin-mode` بالـCSS.

| نوع التعديل | أين تعدّل |
|---|---|
| ميزة للزبون (صفحة، منتج، سلة...) | `index.html` **و** `admin.html` |
| ميزة للإدارة فقط | `admin.html` فقط |
| ترجمة جديدة لنص يظهر للزبون | كلا الملفين |
| `firebase-adapter.js` / `firebase-config.js` | مرة واحدة (مشترك) |

⚠️ **لو عدّلت ملف ونسيت الثاني، يصير اختلاف صامت يسبب أخطاء لاحقاً.**
**دائماً اسألني: "هل أعدّل الاثنين؟" لو ما كنت متأكداً.**

## الصفحات (`go('pageName')`)
`pg-home` · `pg-games` · `pg-pubg` · `pg-efoot` · `pg-accounts` · `pg-efacc` · `pg-tiktok` · `pg-game` · `pg-help` · `pg-account` · `pg-policy` · `pg-soon`

## 🆕 تدفّق الشراء المدمج (بأسلوب Midasbuy)

**صفحات الألعاب (ببجي و eFootball) لا تفتح درجاً** — كل شي بصفحة واحدة:

```
① بيانات الحساب داخل البطاقة نفسها
   ببجي:     [آيدي اللاعب] [تحقّق]  ← بنفس السطر
   eFootball: [إيميل] [كلمة سر] [حفظ] ← داخل البطاقة

② اختيار الباقة (تتحدّد بإطار برتقالي)
       ↓
③ قسم الدفع يظهر تلقائياً بنفس الصفحة:
   • طرق الدفع (أول واحدة مختارة تلقائياً)
   • كود USSD + زر اتصال/نسخ
   • رفع الإيصال
       ↓
④ شريط سفلي ثابت: السعر + "تأكيد الطلب"
```

**الدوال:** `mbSelect(kind,id)` · `mbPickPay(kind,id)` · `mbRender(kind)` · `mbSetRcpt(kind,url)` · `mbConfirm(kind)`
**الحالة:** `MB = { pubg:{item,pay,rcpt}, icons:{item,pay,rcpt} }`

⚠️ **الإلكترونيات فقط تستخدم السلة والدرج** (`directBuy` → `toggleCart`).

## دوال مهمة أخرى
```
go(page)           التنقل        renderAll()      إعادة رسم شامل
renderHome()       الرئيسية      renderPubg()     باقات ببجي
renderIcons()      الكوينز       renderAccounts() الحسابات
addToCart(id)      السلة         checkout()       إتمام طلب السلة
```

# ② لوحة الإدارة — `admin.html`

ملف واحد (~367 KB)، **219 دالة**، **516 مفتاح ترجمة**.
الدخول: **Firebase Auth** (إيميل/كلمة سر) + الإيميل لازم يكون ضمن `ADMIN_EMAILS`.

## الأقسام (`adminNav('name')`)

**🔴 المتابعة** — `a-status` (حالة المتجر) · `a-analytics` (**التحليلات**)
**📦 الطلبات والدفع** — `a-orders` · `a-pay`
**🛍️ المنتجات** — `a-games` · `a-pubg` · `a-icons` · `a-accounts` · `a-tiktok` · `a-elec`
**🌐 الموقع** — `a-sections` · `a-site` · `a-faq` · `a-pol` · `a-txt`
**💬 التواصل** — `a-chat` · `a-support`
**⚙️ عام** — `a-settings`

## 🆕 قسم التحليلات (`a-analytics`)
**كل الأرقام محسوبة من `ORDERS` الحقيقية — لا بيانات وهمية:**
- 4 بطاقات: المكتملة / النشطة / معدل الإتمام / الإيرادات
- رسم أعمدة: إيرادات آخر 6 شهور + خط الهدف المتقطع
- دونت: توزيع حسب فئة المنتج (تصنيف تلقائي بـ`anCategory()`)
- مسار الطلبات + هدف شهري قابل للتعديل (`DB.set.revGoal`)
- أداء المشرفين (من `o.statusBy`) + جدول أفضل المنتجات

**الدالة:** `renderAnalytics()` — تُستدعى تلقائياً عند فتح القسم.

## ميزات إدارية أخرى
- **رفع صور من الجوال** لكل المنتجات (`wireImgUpload`) مع ضغط تلقائي
- **تعديل + ترتيب (▲▼)** لكل المنتجات
- **نافذة تأكيد** قبل أي تغيير حالة (`confirmOrderStatus`)
- **تتبّع هوية المشرف** (من غيّر الحالة / من ردّ بالمحادثة)
- **محرّر النصوص** (`a-txt`) — يدعم **3 لغات**، اتجاه الكتابة يتبدّل تلقائياً
- **وضع الإغلاق** بـ3 تصاميم

## 🆕 حالات الطلب (6) — التسمية تتغيّر حسب النوع

| القيمة الداخلية | 🎮 رقمي (ألعاب/حسابات) | 📦 مادي (إلكترونيات) |
|---|---|---|
| `new` | جديد | جديد |
| `accepted` | مقبول | مقبول |
| `shipping` | **جارٍ الشحن** | **في الطريق** |
| `delivered` | **تم الشحن** | **تم الاستلام** |
| `rejected` | مرفوض | مرفوض |
| `refunded` | مسترجع | مسترجع |

**الدوال:** `isDigitalOrder(o)` · `stLabel(status, order)` ← **لازم تمرّر الطلب دائماً**

⚠️ **القيم الداخلية ثابتة** — التحليلات تعتمد عليها. غيّر التسمية فقط، لا القيمة.

## ⚠️ قاعدتان مهمتان
1. طلب حساب eFootball يتحوّل لـ`accepted` → **الحساب ينحذف تلقائياً** من المتجر (فريد، ما يُباع مرتين)
2. الطلبات القديمة بلا `kind` → `isDigitalOrder()` يستدل من وجود `pid`/`gEmail`/غياب `addr`

# 🎨 هوية التصميم — Clarity

```css
--orange:  #3D5AFE   /* الأساسي (أزرق — الاسم قديم لكن القيمة جديدة) */
--yellow:  #00B589   /* الثانوي (أخضر) */
--navy:    #0D1424   /* الداكن */
--bg:      #F6F7FB   /* خلفية الصفحة */
--white:   #FFFFFF
--line:    #E6E9F0
--text:    #0D1424
--muted:   #5B6478
--r:       16px      /* نصف قطر الحواف */
```
**الخط:** `IBM Plex Sans Arabic` · **الاتجاه:** RTL · وضع ليلي/نهاري/تلقائي

⚠️ **أسماء المتغيّرات القديمة محفوظة عمداً** (`--orange`, `--navy`) حتى لا تنكسر الأنماط — لكن قيمها من لوحة Clarity.

## معايير الاستخدام المطبّقة
- **لا خط أصغر من 12.5px** (`.78rem`) — العربية تحتاج حجماً أكبر
- **أهداف اللمس ≥ 48px** للحقول والأزرار الرئيسية
- **حالة تركيز واضحة** على كل الحقول
- الأخضر = نجاح · الأحمر = خطأ · ذهبي = عملة UC (ألوان دلالية — لا تغيّرها)
