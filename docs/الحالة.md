## ⚖️ قرارات محسومة — لا تُناقَش ثانية

1. Next.js 16 + Vercel — **لا HTML ولا Netlify**
2. الإنجليزية افتراضية بلا بادئة · `ar` (RTL) · `so`
3. Firebase مؤجّل للمرحلة ٣ — البيانات في الملفات حالياً
4. الرئيسية = إلكترونيات · الألعاب = UC + Coins · الحسابات = تيك توك + eFootball
5. تيك توك = **بيع حسابات**، لا متابعين
6. متجر عالمي — دفع دولي + محلي
7. أسماء الألوان القديمة محفوظة عمداً (`orange`=أزرق، `yellow`=أخضر)
