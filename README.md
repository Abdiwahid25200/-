## SomNet — متجر باقات الإنترنت

صفحة واحدة مستقلة (HTML + CSS + JavaScript فقط، بدون أي مكتبة خارجية)، بواجهة عربية RTL.

### المزايا

- **٦ مشغّلين**: هرمود، سومتل، تيليسوم، جوليس، أمتل، ناشن لينك.
- **٣٢ باقة** موزّعة على: يومية، أسبوعية، شهرية، تواصل اجتماعي، وليلية.
- **كشف المشغّل تلقائياً** من بادئة رقم الهاتف الصومالي (يقبل صيغ `61…` و`061…` و`+252…`).
- **تصفية وبحث وترتيب**: حسب المشغّل، المدة، السعر، الحجم، وأفضل قيمة للجيجا.
- **سلة مشتريات** مع تعديل الكميات وأكواد الخصم، محفوظة في `localStorage`.
- **إتمام طلب** مع التحقق من الأرقام واختيار المحفظة (EVC Plus، WAAFI، eDahab، ZAAD، Sahal، Premier Wallet).
- **إيصال إلكتروني** قابل للنسخ + سجل طلبات محلي.
- **تبديل العملة** بين الدولار والشلن الصومالي، و**وضع ليلي**، وتصميم متجاوب للجوال.

### التخصيص

كل الإعدادات في أعلى وسم `<script>` داخل `internet.html`:

| الثابت | الوظيفة |
| --- | --- |
| `SOS_RATE` | سعر صرف الشلن مقابل الدولار |
| `SERVICE_FEE` | رسوم الخدمة لكل طلب (بالدولار) |
| `COUPONS` | أكواد الخصم ونِسَبها |
| `OPERATORS` | المشغّلون وألوانهم وبادئات أرقامهم ومحافظهم |
| `PACKAGE_ROWS` | الباقات: `[المشغّل, النوع, الاسم, الجيجا, الأيام, السعر, الوسم]` |

### تنبيه

الأسعار وأحجام الباقات وبادئات الأرقام **بيانات تجريبية للعرض فقط** — راجعها مع كل مشغّل قبل الاستخدام الفعلي.
كذلك عملية الدفع محاكاة داخل المتصفح (دالة `submitOrder`)؛ لتشغيلها فعلياً استبدلها بطلب حقيقي إلى خادم يتكامل مع بوابة الدفع.
