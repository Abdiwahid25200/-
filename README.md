## 🎨 هوية Clarity

| المتغيّر | القيمة | الاستخدام |
|---|---|---|
| `--color-orange` | `#3D5AFE` | الأساسي (أزرق — الاسم قديم عمداً) |
| `--color-yellow` | `#00B589` | الثانوي (أخضر) |
| `--color-navy` | `#0D1424` | الداكن |
| `--color-bg` | `#F6F7FB` | خلفية الصفحة |
| `--color-surface` | `#FFFFFF` | خلفية البطاقات |
| `--color-line` | `#E6E9F0` | الحدود |
| `--color-muted` | `#5B6478` | النص الثانوي |
| `--radius-card` | `16px` | نصف قطر الحواف |

**معايير مطبّقة:** لا خط أصغر من 12.5px · أهداف لمس ≥ 48px · حالة تركيز واضحة · RTL افتراضي · وضع ليلي/نهاري.
