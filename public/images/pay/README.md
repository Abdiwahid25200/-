# شعارات وسائل الدفع

ضعي هنا الشعار الحقيقي لكل خدمة، ثم اكتبي مساره في `lib/data.ts` ← `pay` ← `logo`.

مثال:

    { id: "p1", nameAr: "EVC Plus", …, logo: "/images/pay/evc.png" }

بلا `logo` تظهر العلامة المرسومة بلون الخدمة — فلا ينكسر شيء قبل رفع الصور.

المقاس المناسب: مربّع ١٢٠×١٢٠ بكسل على الأقل، بخلفية شفّافة (PNG) أو SVG.
