# 🖼️ صور المتجر

ضعي الصور هنا، ثم أضيفي مسارها في `lib/data.ts` بحقل `img`.

## المجلدات

| المجلد | لأي قسم |
|---|---|
| `elec/` | الإلكترونيات (الرئيسية) |
| `pubg/` | باقات شدات ببجي |
| `efootball/` | باقات كوينز eFootball |
| `tiktok/` | خدمات تيك توك |
| `accounts/` | حسابات eFootball |

## مثال

```ts
{ id: "e1", name: "سماعة بلوتوث", price: 32, img: "/images/elec/headset.jpg" }
```

## إرشادات

- **الصيغة:** WebP أفضل · وإلا JPG للصور و PNG للشعارات
- **المقاس:** مربّع 800×800 للمنتجات · 1200×750 لبطاقات الأقسام
- **الحجم:** أقل من 300 كيلوبايت للصورة
- **بدون صورة؟** تظهر أيقونة القسم تلقائياً — لا شيء ينكسر

> ⚠️ لا ترفعي صوراً تخصّ متاجر أخرى — استخدمي صور منتجاتك أو صوراً مرخّصة.
